# Project Summary:

In this project, you will design and build a distributed application that performs a specific business process or application logic. The distributed system should be deployed in the cloud and include at least three components from the following: messaging, queuing, caching, and databases. You'll have the opportunity to understand how these components interact and how they can be leveraged to achieve scalable and efficient system architecture. Additional technology like storage or virtual machines can be incorporated, but avoid using functions, containers, Kubernetes, or service mesh.

## Learning Objectives:

- Apply cloud computing concepts by designing and implementing a distributed application that integrates at least three core components (messaging, queuing, caching, databases).
- Analyze the interactions between system components to evaluate their impact on scalability, performance, and efficiency. 
- Evaluate different cloud deployment strategies to determine the most effective configuration for the distributed system.
